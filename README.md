# Awesome Bouyon [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of resources about **bouyon**, the music genre created in Dominica in the late 1980s: its history, styles, artists, riddims, festivals and playlists.

Bouyon mixes Dominica's jing ping, cadence-lypso, bele, quadrille and chante mas with electronic keyboards, drum machines and fast synthetic bass. The name is Antillean Creole for a soup where everything cooks together. The most complete reference is [Bouyon Musique, the bouyon music encyclopedia](https://bouyonmusique.com/en/), with 400+ English pages.
